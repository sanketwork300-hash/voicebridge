    Help

    Short answers. The full guide is in the project README.

    Live translation
    Pick the spoken language and the language to translate to, then press “Start listening”. The browser asks for microphone access once. Text appears first; speech follows if “Text and speech” is selected. To translate a browser tab instead of your microphone, use the VoiceBridge browser extension.
    Translating a file
    Drop an audio or video file, check the languages, press “Translate”. You get translated audio, subtitles, and for video a dubbed copy with the picture untouched. Long files take a while; you can close the page and come back to “Recent files”.
    Which engine?
    VoiceBridge Cascade recognises speech, translates the text with context, then speaks it. It skips music, laughter and noise, and gives accurately timed subtitles. Meta Seamless translates speech to speech directly; its models are licensed for non-commercial use only and need a lot of memory.
    Why was part of my audio not translated?
    Music, sound effects, laughter and silence are skipped on purpose, and text the recogniser probably invented is dropped. “Activity details” lists what was skipped and why.
    It says “mock mode”
    The server is running without real models, so the output is a fixed demo script. Ask whoever runs the server to configure real providers.
